Where to ask

Bugs, questions and feature requests: the repository's issue tracker. Email: hello@corsen.ai. Please never paste a pairing code, a page's content, or anything from a signed-in site into a report.

Prerequisites

DeepSeek Harness (dsh) 0.1.2-rc.1 or newer, Node.js 22.19 or newer, and pnpm on PATH — dsh plugin forwards to pnpm and DeepSeek Harness does not install it (npm install -g pnpm). The installers check for all three before creating anything.

Known limitations

  • Pages Chrome protects (chrome://, the Web Store) cannot be attached; the panel marks them as restricted.
  • Sites that require trusted input events may not respond to the connector's synthetic clicks; the failure is reported as a failed action, never as a success.
  • On Windows, dsh plugin add splits a path containing a space (an upstream limitation); the installer works around it with the file's short name.
  • Content inside iframes and inside shadow DOM is not read or acted on in this version: the page code runs in the tab's top document and does not descend into either.
  • Secret masking is by the signals a page gives; a field with no telling type, attribute, name or label cannot be told from an ordinary one.
  • A screenshot is pixels and is not masked: it shows the attached tab as you see it. Chrome captures only the tab at the front of its window, so a covered attached tab is brought to the front first, and the result says so.
