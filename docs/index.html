What it does

A Chrome extension and a small local companion let one exact DeepSeek Harness session — running on your own computer — read and act in the browser tabs you explicitly attach to it, inside the Chrome profile you are already signed in to. No hidden automation browser, no guessing which tab belongs to which task. The panel always shows the route in plain words: DeepSeek session → Chrome profile → attached tabs.

It never reads or acts in a tab you did not attach, never reads your cookies, history or saved passwords, masks passwords, one-time codes and payment fields inside the page before anything leaves the browser (a screenshot, taken only when the session asks for one, shows the page as you see it), and sends nothing to Corsen AI: the extension talks only to the companion on 127.0.0.1.

Install

Requires DeepSeek Harness (dsh), Node.js 22.19 or newer, and pnpm on PATH (dsh plugin forwards to it: npm install -g pnpm).

dsh plugin --profile web add @corsen-ai/dsh-browser-connector
npx dsh-connector-broker --pairing-code

Then install the Chrome extension from the Chrome Web Store, open its side panel, type the pairing code once, pick your session, and press Attach this tab. Installers that also start the companion and check the setup are in the repository (scripts/install.sh, scripts/Install Connector.cmd).

Evidence

Every claim above is a test in the repository: routing and isolation, transport security, redaction, honest reporting, a page built to give a model instructions, an attached tab that changes site mid-task, recovery from a killed worker, broker or Chrome, the released pair installed into a real dsh, and one live turn of a real dsh process. The test matrix and the evidence say what was run, where, and what is not proven.
